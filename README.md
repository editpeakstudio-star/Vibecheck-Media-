🌟 About The Project

Vibecheck-Media is a modern web development project designed to deliver an engaging, responsive, and user-friendly digital experience.

Built using modern frontend technologies, the project focuses on maintainable code, optimized production builds, and reliable web hosting.

The application is deployed through Firebase Hosting, making the production website accessible online.

- ⚡ Maintain optimized production performance.

- 🔥 Use reliable cloud hosting.

📥 Installation & Setup

Follow these instructions to run the project locally.

1️⃣ Prerequisites

Make sure you have installed:

- Node.js
- npm
- Git

2️⃣ Clone Repository

git clone https://github.com/editpeakstudio-star/Vibecheck-Media.git

3️⃣ Navigate to Project

cd Vibecheck-Media

4️⃣ Install Dependencies

npm install

5️⃣ Start Development Server

npm run dev

The development server will provide a local URL in the terminal.

---

🏗️ Production Build

Create an optimized production build:

npm run build

Vite generates the production-ready files inside:

dist/

👀 Preview Production Build

npm run preview

---

🔥 Firebase Hosting Deployment

This project uses Firebase Hosting for production deployment.

Deployment Requirements

- Firebase CLI installed
- Firebase account authenticated
- Correct Firebase project selected
- Production build generated

Step 1: Firebase Login

firebase login

Step 2: Select Firebase Project

firebase use vibecheck-media

Step 3: Build Project

npm run build

Step 4: Deploy Website

firebase deploy --only hosting --project vibecheck-media

🌐 Production URL

https://vibecheck-media.web.app
